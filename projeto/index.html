Home

Esta é a página inicial da minha avaliação de Programação Web Frontend

Esta página conta com modo claro e escuro de acordo com a preferência do navegador/sistema!

Este trabalho conta com 4 páginas:

  • Index (Home);
  • Login;
  • Cadastro;
  • Admin;
  • Currículo.

Essas páginas consistem em: Apresentação do projeto como um todo, Um formulário com Login e Senha, apenas de exposição (sem validação externa de dados), Um formulário de cadastro (sem salvamento local ou externo de dados) e uma página com formulário de cadastro de login e senha (que os salva no localStorage e exibe os salvos na própria página), e meu currículo respectivamente.
